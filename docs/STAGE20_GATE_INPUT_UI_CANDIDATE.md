# Stage 20 河口堰開門入力UI候補

## 位置づけ

この文書は、`stage20-hybrid-gui.html` に置く河口堰1〜8番水門の入力UI契約を固定します。対象はGUI表示、操作説明、静的検証だけです。

この候補は Stage 20 の物理solver、応答pack、合成Worker、凍結メッシュ、事前計算、公開シミュレーターへ接続しません。水門状態を変更しても流速・水深・流向・時刻系列は変化せず、地図には「流れの図には未反映」と表示します。

## 2つのモード

### 自動推定

- 現在選択中の時刻にある全体開門率を0〜1へ収め、`round(全体開門率 × 8)` で整数の開門段階0〜8を推定します。
- 推定段階を固定順序 `5 → 4 → 6 → 3 → 7 → 2 → 8 → 1` で、1〜8番水門それぞれの0%（閉）または100%（開）へ変換します。
- 各門を一律の中間開度、たとえば全門50%として扱いません。
- 時刻を変更した場合は自動推定を更新します。

### 現地目視入力

- 1〜8番を個別に開（100%）または閉（0%）で入力します。
- 現地入力が有効な間は、自動推定を表示上で明示的に上書きします。
- 入力元と観測時刻を現地入力に付随するメタデータとして表示します。
- 現在時刻の自動推定と異なる水門番号、および差の門数を表示します。
- 「自動推定へ戻す」で現地入力による上書きを終了し、現在時刻の自動推定を再び有効にします。

入力値とメタデータは、この画面を開いている間だけの表示メモです。再読み込み、物理計算、応答pack更新、外部送信、公開画面反映は行いません。

## 固定開門順序と9状態

各行は、水門番号1〜8の順です。値は0%が閉、100%が開を表します。

| 段階 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 開いている門 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | なし |
| 1 | 0 | 0 | 0 | 0 | 100 | 0 | 0 | 0 | 5 |
| 2 | 0 | 0 | 0 | 100 | 100 | 0 | 0 | 0 | 5, 4 |
| 3 | 0 | 0 | 0 | 100 | 100 | 100 | 0 | 0 | 5, 4, 6 |
| 4 | 0 | 0 | 100 | 100 | 100 | 100 | 0 | 0 | 5, 4, 6, 3 |
| 5 | 0 | 0 | 100 | 100 | 100 | 100 | 100 | 0 | 5, 4, 6, 3, 7 |
| 6 | 0 | 100 | 100 | 100 | 100 | 100 | 100 | 0 | 5, 4, 6, 3, 7, 2 |
| 7 | 0 | 100 | 100 | 100 | 100 | 100 | 100 | 100 | 5, 4, 6, 3, 7, 2, 8 |
| 8 | 100 | 100 | 100 | 100 | 100 | 100 | 100 | 100 | 5, 4, 6, 3, 7, 2, 8, 1 |

`gatePatternForStage(stage)` は上表の数値配列を返します。`classifyGatePattern(levels)` は完全一致する場合に段階0〜8を返し、一致しない場合は `null` を返します。

## 現地入力の判定

- 現地入力が上表のいずれかと完全一致する場合は「標準段階0〜8」と表示します。
- それ以外の組合せは入力を拒否せず、「標準順序外」と警告します。
- 「標準順序外」は固定順序との不一致を表す表示上の警告であり、現地観測の誤りを意味しません。
- 自動との差は、各門を0%か100%として比較します。開閉が異なる門だけを差として数えます。

## 表示契約

GUIには少なくとも次を同時に確認できる領域を置きます。

- モード: 「自動推定」「現地目視入力」
- 自動推定値: 段階0〜8と、固定順序から得た1〜8番の開閉
- 有効値: 現在地図に重ねている1〜8番の開閉
- 現地入力メタデータ: 入力元、観測時刻
- 比較: 自動推定との差
- 分類: 標準段階、または「標準順序外」
- 操作: 「自動推定へ戻す」
- 非接続表示: 「流れの図には未反映」
- 位置固定: 水門1〜8と魚道は、固定された `onga_geometry.geojson` の提供緯度経度をそのまま表示へ投影する

水門1〜8の中心位置と魚道位置は写真抽出やメッシュセル中心へスナップしません。岸線補正で移動できるのは周囲の水面・陸地境界だけです。魚道の表示中心を上流・下流メッシュセルの平均で置き換えることも禁止します。

## 非接続境界

この候補で変更してよいのは、`stage20-hybrid-gui.html`、`stage20-hybrid-gui.css`、`onga_stage20_gui.mjs`、`onga_stage20_gui_data.mjs` の固定座標読込、GUI文書、静的validatorです。

次は変更禁止です。

- `onga_stage20_gui_data.mjs` から合成Workerへ渡すメッセージ（魚道の固定表示座標はWorkerへ渡さない）
- `onga_stage20_hybrid_worker.mjs` の入力契約
- Stage 20物理solver、応答pack、メッシュ、事前計算結果
- 公開シミュレーター、公開配信、`main` 反映

## 静的検証

```sh
node tools/validate_stage20_hybrid_gui.mjs
```

validatorは、操作要素、固定順序、9つの0/100%状態、標準・順序外判定、メタデータ、差表示、自動復帰、非接続境界を確認します。画面の最終採用は判断画像の確認後に行います。
